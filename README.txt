SZC SINGLE-PAGE WEBSITE
=======================

This is a static, deploy-ready website. The main website is now a single page:
- index.html — all sections and service information
- style.css — responsive visual system and layout
- script.js — mobile navigation and active-section state

The former individual service pages have been removed from this package. The sitemap now lists only the homepage. The existing logo, icon, manifest, social preview image, robots.txt, 404 page and GitHub Pages workflow are retained.

DEPLOY
1. Extract the ZIP.
2. Upload the contents of this folder to the root of your hosting account, or push the folder contents to the configured GitHub Pages repository.
3. Confirm https://szcwebsites.in/ loads and that /sitemap.xml contains only the homepage.
4. Submit the updated sitemap in Google Search Console.
