# SZC Websites SEO/GEO proposal — review before deployment

This is a proposed local package. It has NOT been deployed to the live website.

## Changes in this proposal
- Added four focused service pages: web design, e-commerce, web app development and maintenance.
- Added unique title, meta description, canonical URL, social metadata and Service JSON-LD to each service page.
- Added internal links from the homepage service cards, service-page navigation, cross-service links and footer.
- Updated sitemap.xml to list the homepage and four service pages.
- Preserved the existing main stylesheet, JavaScript, logo, contact flow, hosting workflow and brand assets.
- Kept copy factual and avoided fabricated reviews, client results, guarantees or keyword stuffing.

## Before deployment
1. Review each page's service scope and ensure every claim accurately describes the services offered.
2. Test the pages locally on mobile and desktop, including navigation and contact links.
3. Validate HTML, JSON-LD and sitemap XML.
4. Confirm canonical URLs and that all listed URLs return HTTP 200 after deployment.
5. Submit `https://szcwebsites.in/sitemap.xml` in Google Search Console.
6. Use URL Inspection for each new page and request indexing if appropriate; Google does not guarantee indexing.
7. Confirm the live `robots.txt` allows intended crawlers and that the hosting/CDN does not block them.
8. Compare search performance after enough data accumulates; don't expect immediate ranking changes.
